# Vault Object Lexicon

## Canonical terms

- **task**: single actionable work unit with clear done criteria
- **workflow**: repeatable sequence used to execute a class of work
- **skill**: reusable execution wrapper (human or agent-operable)
- **decision**: durable record of a meaningful choice and rationale
- **lexicon**: canonical definitions used to reduce ambiguity
